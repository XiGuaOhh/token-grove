# 小站萌圆体 / Token Grove Rounded

本字体由寒蝉全圆体 ChillRoundF Regular v3.200 衍生，继续按 SIL Open Font License 1.1 发布，完整授权文本见 OFL.txt。

上游作者与项目：https://github.com/Warren2060/ChillRound
原始版本：https://github.com/Warren2060/ChillRound/releases/tag/v3.200

本版保留原始字形轮廓及版权信息，修改了字体名称，并加入小字号灰阶平滑规则。新名称为“小站萌圆体 / Token Grove Rounded”，以遵守上游的保留字体名称要求。上游作者未参与本应用的开发。

prepare_font.py 使用 Python 标准库从上游 Regular TTF 重建本字体，并校验字形轮廓与字体校验和。运行软件无需 Python，也无需把字体安装到系统。
