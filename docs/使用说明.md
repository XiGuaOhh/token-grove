# Token Grove Desktop 2.7

双击 Token Grove.exe 启动。Windows 10 / 11 x64，使用系统 .NET Framework 4.8，无需安装 Node 或浏览器内核。复制便携版时请保留 fonts 文件夹。

## 软件更新

设置页底部新增软件更新，也可从悬浮窗右键菜单进入。默认每 6 小时检查 GitHub 正式 Release，重开软件不重复检查；有新版时入口显示小圆点，可查看更新说明并直接下载便携包。自动检查可以关闭，手动检查随时可用。

下载显示进度并验证 SHA-256；完成后打开文件夹，完整解压到新文件夹，退出托盘里的旧版，再运行新文件夹的 Token Grove.exe。保留 fonts 文件夹，个人计划和设置自动沿用。不会自动运行下载的软件；检查失败不会误报已是最新版。

## 计划与灵感

点边栏日历图标进入计划页，再点“新计划”。标题与内容会自动保存；Ctrl+S 可手动保存，Ctrl+N 可新建。选择客户端后可按额度重置提醒、指定时间提醒，或只记录。点击“复制计划”可复制标题和完整要求，粘贴到相应客户端继续。

额度提醒保存当前已用完窗口的重置时间，多个额度同时用完时等待最晚一次。没有有效时间时不猜测；后续读到新额度信息后继续判断。指定日期按本机时间解释。提醒复用现有每分钟检查，客户端需要保持运行或留在托盘；完全退出期间的到期计划会在下次启动时补提醒。

点击托盘提醒会打开计划；计划入口的小圆点也会标记待处理内容。完成后可移到“已完成”，也可恢复为待办。计划统一保存在 %USERPROFILE%\.token-grove\plans.json，上一版保存在 plans.json.bak。从 Codex 启动、双击启动或换软件文件夹都使用同一份计划。首次升级自动合并普通目录和 Codex 私有目录里的旧计划，原文件及 migration-backups 迁移备份保留；冲突内容分别保留，已迁移的文件不会重复导入。发布包和快照导出不包含个人计划。读取文件失败时保留原文件，不会用空列表覆盖。

## 预估余量

每个窗口的估算公式为：本机样本 Token ÷ 官方已用比例 × 剩余比例。只使用同一提供方、同一额度窗口、截至官方采样时刻的本机记录。5 小时与每周独立计算，不共用同一份余量。

仅在窗口时间已知、比例大于 1% 且小于 100%、样本至少 1,000 Token、官方采样在 30 分钟内时显示。缺少条件时显示“—”；额度已重置、窗口已结束或样本过期后不沿用旧预估。鼠标停在额度区域可看说明。

这不是官方 Token 余额：不同模型、缓存、网页端与其他设备会影响实际消耗。ChatGPT 栏为 Codex 订阅额度，不代表 ChatGPT 网页各模型的消息上限。

## 用量查询

左侧第二个图标打开用量页。支持今天、昨天、近 5 小时、近 7 天、近 30 天、全部历史，以及自定义日期和分钟。开始计入，截止不计入。近 7 天包含今天和前 6 个本地日历日，近 30 天包含今天和前 29 日。每周额度单独使用官方重置时间，可在额度窗口上悬停查看起止及统计截至时间。

可按 Claude / Codex 和模型名称筛选，查看模型、每日、逐条记录及额度窗口。记录按新到旧排列，每页加载 50 行；导出 CSV 包含当前筛选范围的全部记录。输入框、日历、记录分页、CSV 导出仍然保留。统计覆盖本机可读日志与 Codex 归档会话，不含网页端、其他电脑和已删除日志。

Claude 的同一请求只计一次，包含新增输入、输出、读缓存、写缓存。Codex 总量使用已包含缓存的输入。上方“缓存”显示读写合计，悬停可看各项数字及命中率。和其他工具对账时，可用同一时间范围、客户端日志和模型进行比较。

## 账号与常驻

自动读取本机已登录 Claude Desktop / Claude Code 和 Codex。Claude Desktop 与 Code 分别检测，兼容 Microsoft Store 安装；不会把打开桌面版误当成 CLI 未登录。额度读取使用已有授权，不读取浏览器 Cookie、不刷新或改写登录、不保存或导出令牌。兼容接口不可用时会标记缓存或未知。

Codex 的账号和额度接口仅在同步时启动短时原生子进程，同步后退出，不请求模型推理。默认每 5 分钟同步，可改为 10 或 30 分钟。日志按字节位置增量读取，流式与累计上报去重。

关闭主窗口会转入悬浮窗；托盘可显示、隐藏、刷新、改外观和退出。开机启动默认关闭，可在设置中自行开启。再次启动会唤回现有实例。偏好、窗口位置、快照和同步摘要保存在 %LOCALAPPDATA%\TokenGrove。

## 验证与文件

本版在 Windows 桌面环境通过 145 项原生回归检查，覆盖跨会话去重、日志重写、窗口用量、页面恢复、查询状态、滚动位置、毛玻璃、底板透明度、计划持久化和提醒。空闲后停止连续动画，原生输入控件的清晰显示缓冲仅在交互时更新。占用受界面、日志和系统影响，详见《性能实测.md》。

完整 C# 源码与 build.ps1 构建脚本位于 GitHub 仓库，可用 .NET SDK 重新编译。便携包运行不需要 SDK。支持 --widget、--dashboard、--self-test 和 --query 参数。旧版 JSON 快照仍可导入，快照含账号元数据但不含令牌，离线快照不含逐条日志。

字体为基于寒蝉全圆体 v3.200 衍生的小站萌圆体，采用 SIL OFL 1.1，详见 fonts/OFL.txt 与 NOTICE.md。客户端矢量图标来源 Lobe Icons，MIT 许可见 licenses/LobeIcons-LICENSE.txt。
