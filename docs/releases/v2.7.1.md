修复计划在不同启动方式下显示不同的问题。

- 从 Codex 启动和手动双击运行，现在都使用 `%USERPROFILE%\.token-grove\plans.json`，避免 Windows 对 AppData 的重定向产生两份数据。
- 首次升级会合并普通目录与 Codex 私有目录里的旧计划，保留全部原文件，并在 `migration-backups` 留存备份。
- 相同计划的不同编辑内容会分别保留，不静默覆盖；迁移成功后不会重复导入，也不会把主动删除的旧计划恢复回来。
- 旧文件异常时保留原文并提示；共享计划文件异常时禁止覆盖，防止误清空。

通过 134 项原生回归检查，包含两种启动来源合并、重启编辑保留、冲突保护、删除不复活和损坏文件保护。无额外后台进程或持续轮询。更新包不包含个人计划。
