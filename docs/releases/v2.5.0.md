# Token Grove v2.5.0

首个 GitHub 发布版本，Windows x64 便携应用。

- 自动读取本机 Claude Desktop / Claude Code 与 Codex 额度。
- 分别展示 5 小时、周额度和对应的预估 Token 余量。
- 支持历史日期与分钟查询、模型筛选、趋势、记录分页和全量 CSV 导出。
- 雾蓝 / 石墨灰主题、Windows 11 毛玻璃、独立不透明度。
- 328 × 116 悬浮窗，系统托盘、置顶与可选开机启动。
- 原生 WinForms / GDI+，无浏览器内核或常驻 Node。

## 下载与运行

下载 **Token-Grove-v2.5.0-Windows-x64.zip**，完整解压后运行 **Token Grove.exe**。请保留同目录的 **fonts** 文件夹。需要 Windows 10 / 11 x64 与 .NET Framework 4.8；系统毛玻璃需要 Windows 11 22H2 或以上。

附带 **SHA256SUMS.txt**，可用于核对下载文件。

## 验证

已从发布源码独立构建并通过 43 项原生回归检查。发布包不包含账号、凭据、聊天日志或个人用量快照；仓库预览为合成演示数据。

ChatGPT 栏对应 Codex 订阅额度；本机 Token 统计不含网页和其他设备。预估余量不是官方余额，缺少窗口或有效样本时显示“—”。
