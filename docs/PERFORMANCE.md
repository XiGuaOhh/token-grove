# 性能说明

Token Grove 使用 WinForms / GDI+ 和 Windows 系统背景材质；没有浏览器内核、常驻 Node 服务或桌面截图模糊循环。

悬浮窗只保留额度百分比和进度条。交互或数据更新时短暂动画，停止或隐藏后释放连续绘制与高精度计时。同步默认每 5 分钟一次，日志从已读取的字节位置继续解析。

记录页每次只建立 50 行，长范围图表限制约 60 个区间，统计采用单次遍历。实际占用会随日志量、打开的页面、文件对话框和系统状态变化；请以任务管理器或“关于 / 资源占用”为准。

测试覆盖 43 项原生回归，以及滚动、原生毛玻璃开关、窗口样式与首次打开查询。性能样例不是任意机器上的固定承诺。
